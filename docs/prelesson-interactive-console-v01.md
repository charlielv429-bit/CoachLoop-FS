# 课前动态备课控制台 V0.1

日期：2026-10-30（北京时间）。基于最新main `7c72b13`，保留PR #1—#9。新增的是可交互本地应用，不是静态演示报告，也不代表Coze网关已打通。

## 已确认的最小缺口与本轮交付

原main已有受保护的课前HTTP API、LangGraph和教案Agent，缺少教师表单、动态响应展示与浏览器安全调用边界。本轮只补这三层，原API、main部署入口、数据库、视频和七要素实现均未修改。

实际链路：浏览器填写条件 → 本机POST `/api/v1/lesson-plans/draft` → 原 `create_router` Bearer校验/精确JSON/输入模型 → 原 `run_prelesson` → 原输出校验 → 动态展示七要素、三阶段时间、预计负荷和安全提示。不是读取静态example-response，也没有新写一套教案生成逻辑。

这是现有**确定性教案Agent**的真实动态调用，不是已部署的大模型对话Agent。仅支持零基础《冰上双足滑行与身体姿态控制》45分钟，草稿必须交教师复核，知识未核实、预计负荷和安全待确认标记不变。没有教师身份认证、批准按钮、审核写回或数据库自动归档。

## 在已有项目环境中打开

同步本分支后，Mac可双击 `scripts/start_prelesson_console.command`，再打开终端显示的 `http://127.0.0.1:8767`。这是一次启动操作，无需输入生产Token，也不需要重复诊断命令。关闭终端或按Ctrl+C停止。

工程入口：`.venv/bin/python scripts/run_prelesson_console.py`，可用 `--port` 指定其他本地端口。没有 `--host` 参数，只绑定127.0.0.1。必须使用仓库已有Python3.12及已安装依赖的环境；.command优先用项目.venv，缺失则尝试python3，不自动安装或升级任何依赖。当前云环境已实际验证；用户Mac未挂载，不能声称Mac环境已安装完毕。若Mac仅运行过标准库诊断脚本，仍需先具备本项目运行依赖。

页面填写匿名班级、人数、实际师资、场地器材后点“生成教案草稿”。输入变更即隐藏旧结果；请求失败不保留旧教案冒充新结果；可下载完整JSON草稿，下载不等于教师批准。页面没有真实学生示例、不上传视频或健康信息。

## 安全边界

- **独立本机服务**：不挂载到main，不改变 `.coze` 或生产路由白名单，不提供Coze网关旁路，不可公开部署/反向代理/公网端口转发。它只为本机可信使用者生成草稿，不是多用户教师账号系统，不能隔离恶意本机程序或其他有回环访问能力的本地用户。
- 只接受直接127.0.0.1客户端、固定Host/端口及HTTP；拒绝转发头、非回环客户端、错误Host、重复Host和跨站访问。其他路径/方法404，WebSocket1008关闭，无CORS授权。
- 本机页面用每次进程启动重新生成的HttpOnly/SameSite=Strict会话Cookie。POST必须同时具备Cookie、精确同源Origin、固定自定义头和JSON内容类型；重启后旧Cookie失效。Cookie仅用于本地HTTP，因此不设置Secure，不能移作生产会话方案。
- 只有通过本地会话/CSRF检查后，独立边界才在服务端注入一次性内部Bearer，继续由**未经修改的原API**验证。浏览器不输入、读取或保存Bearer；请求中自带Authorization会被拒绝。本机Cookie不是Coze平台凭据，也不是教师审核身份。
- 不读取 `COACHLOOP_PRELESSON_TOKEN` 生产值，不连接Coze、数据库或模型服务，不将凭据写入URL、HTML、JS、localStorage或sessionStorage。不使用静态响应兜底。
- 所有动态文本通过textContent/DOM节点展示，无innerHTML、eval或外部脚本；CSP只允许同源脚本/样式/请求，禁止嵌入；响应no-store、no-referrer。接口保留原1MiB限制、重复JSON键和脱敏错误保护。错误响应不会进入展示/下载。
