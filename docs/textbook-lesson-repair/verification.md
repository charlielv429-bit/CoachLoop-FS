## 如何防止凭空引用与旧证据继续打印

1. 每个摘要固定对应知识ID、版本、完整知识摘要及P3.4原页材料声明。必须在本机找到与仓库P3.4版本、声明所有字段精确匹配的当前条目，才显示该摘要。
2. 空库、只导入知识而未恢复声明、同名但内容不同的材料、后续新版本或拒绝状态均不能匹配；显示具体缺项。
3. K011仍是课程自拟提取原则；K018仍是课程自拟三课次方案。教材练习素材与课程安排分栏，不改变content_kind或lesson_ids。
4. 保存的教师文字是待审核历史，不是独立证据。生成文字带教材事实标识；对应版本/声明失配后，旧稿页面提示历史失效，服务端拒绝打印，须重新载入并复核。不会删除旧版本。教师自行删改的文字始终是未认证编辑，不能因此取得正式依据资格。
5. 未扩大受控审核范围：`formal_teaching_evidence`、`technical_guidance`仍为空；资源、先修和专项不足时继续暂缓。离线PDF不会自动随证据更新，使用前仍须在线重新核对。

## 教师使用

1. 启动原Mac本机控制台，打开教师工作台；空库先阅读用途和范围后初始化候选资料，已有库不覆盖。
2. 进入智能教案，选择L05；查看“教材直接支持的事实”“课程建议”“分项证据与现场缺口”。
3. 下方教学目标、重点难点、步骤、分层和观察项可编辑；点击“修改这一项”定位右侧输入，保存追加待审版本。
4. 使用“打印／存储为PDF”打开可读HTML，再使用浏览器打印。没有原生Word导出，也不假装已生成PDF；实际测试PDF另附。
5. 材料变化后返回课次重新载入并复核。旧编辑保留为历史；不应复制旧稿冒充当前批准。
