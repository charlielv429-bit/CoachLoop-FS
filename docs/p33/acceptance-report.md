## 页面操作

```sh
PYTHONPATH=src .venv/bin/python scripts/run_prelesson_console.py --port 8767
```

打开 http://127.0.0.1:8767 ，智能备课页展开“按课次备课模式”，选择L05。
填写匿名学情与资源条件，生成9分钟准备、29分钟基本、7分钟结束的框架。
页面新增目标、动作要点、练习步骤、常见错误与待复核问题、安全提示、分层练习、评价观察项七类教师工作区。
教师可修改并追加待复核版本、查看历史、导出JSON；新增六项文字与原目标字段都作为未认证教师填写记录，
不写入共享知识库，不改变专项审核、资源暂缓或阶段时间。

未保存修改时导出/核对会提示先保存，避免误导出旧稿；保存期间继续输入的文字不会被响应覆盖。
资料变化后点击“重新核对资料与引用”或直接导出，会从服务端重新检查资格；条件改变期间到达的旧导出响应会被取消。

版本保存复用原PlanStore：当前服务进程内存、浏览器签名会话隔离、全局100快照/2MiB，退出清空。
同一浏览器配置文件的标签页共享会话；其他浏览器即使知道ID也不能读取。导出副本由教师自行保管。
本阶段不新增教案磁盘持久化、JSON导入或认证通道，知识SQLite/审核/完整备份机制全部沿用P3.2。

## 失效与撤回

沿用P3.2撤回检查，并覆盖新增L05工作底稿的重复引用区。
原受控记录被撤回后，导出和历史中的技术指导、受控引用及新增材料卡正文会撤下，只保留出处/审核ID作为审计。
候选知识版本更新或不再关联L05时，旧草稿的对应材料卡标注superseded_or_unlinked并撤下旧正文，要求重新生成。
不把新版本无声替换进教师旧稿，不继承旧批准，不擦除教师自己的未审核修改记录。
七个非L05课次不生成新L05工作区，原24主题及其API、45分钟算法、资源暂缓、视频模块与私有隔离逻辑保持。

## 真实资料仍缺

1. B02/B03原PDF或授权原页片段、准确章节/版次/图文定位，尤其前压步与后压步边界。
2. L05具体动作要点、练习递进、常见错误、保护与纠错范围的逐条专项意见。
3. 可追溯的专项审核材料/审核人，由现有受控流程核对；不生成身份、签名或审核日期。
4. 真实班级先修、装备适配、场地/人员/等待区、路线间距、保护和应急制度的现场确认。
5. 适用于本课的描述性观察量规；不能套用ISU竞技等级或AI自动分数。

上述证据补齐前，当前交付是可修改、可审阅的设计草稿，不能声称已经可实施专项技术教学。
