# CoachLoop-FS V4.0｜教师工作台

基线main 134c430c1b49af8927f1f55a8a90ae49a1431567，PR #22已合并。
本轮为教师界面产品化：复用课程、知识、视频和闭环，保留现有底层算法、API契约、身份与审核边界。

## 教师日常使用：不需要输入终端命令或理解JSON

在已准备好项目主环境的Mac上，双击scripts/start_prelesson_console.command。
服务仅绑定127.0.0.1，成功启动后尝试自动打开教师首页；若浏览器未打开，可手动访问http://127.0.0.1:8767。
窗口须保持运行，关闭或Ctrl+C会停止本机服务并清空私有进程内存；不会部署公网。

首页四个入口：智能教案、视频动作分析、教师反馈、专项知识库。右上角“高级模式”保留原V1.1多主题、研发参数和结构化导出，地址/advanced。

### 第一次打开资料库为空

1. 点击首页“了解并初始化”，阅读用途和范围后勾选声明，再点击初始化。
2. 只从随项目提交的P3.2/P3.4文件载入23条候选、27个历史版本、50条材料声明、0条系统决定；不联网下载教材。
3. 全部保持pending。资料共享给获授权的本机会话，但不用于私有学生/反馈资料。
4. 任何版本、声明或决定已经存在，就拒绝初始化；不提供覆盖、重置或重复导入。

使用既有Archive、EvidenceBundle、snapshot和SQLiteRegistry.restore_full校验与空库事务；不新增数据库表或批准通道。
来源包字节摘要与已提交的course-inventory清单核对，批次后期校验失败也整批回滚；并发初始化只允许一个成功。
部分已有库不能用初始化补齐：请维护者先备份，沿用既有离线增量流程核对，不在新界面静默修复或丢弃数据。

### 智能教案

- 首页点“打开L05教案”，或从八张课次卡选择任一课。自动载入已有课程自拟草稿与当前知识关联。
- 默认45分钟，准备9、基本29、结束7。20人/12人等预设明确是演示或待确认，先修未确认，不能当作真实学情或现场许可。
- 正文是中文文档：目标、重点难点、准备、流程、组织、安全、分层、评价和修改建议。专项要点未审核时保持待填写，不生成新动作技术或评分。
- 点击“修改这一项”跳到编辑栏，填写后保存为新的待审版本。未保存不能打印；历史在本次进程内保留。
- 每条候选显示ID、版本、source_id、书名、定位与审核提示。原页核验声明不等于系统可信审核；课程自拟内容不归因教材原文。
- 需要真实班级/场地的详细条件时，可显式进入高级模式；普通展示不要求填写全部研发参数。

### 打印与PDF

点击“打印/存储为PDF”打开服务端重新核对过的中文HTML文稿，再点击打印按钮，在Mac打印中选择“存储为PDF”。
本轮不提供Word生成器，不伪装成已经导出DOCX。取消打印不会保存文件；界面只提示已请求打开打印稿。
私有文稿受原计划会话约束；版本或会话过期时只显示中文重核提示，不显示原始JSON错误。
反馈打印也会重新验证当前事件/教案/知识资格，旧确认不被当作当前有效状态。

本轮Chromium验收实际执行HTML打开和Page.printToPDF，生成了[合成教案PDF样例](L05-print.SYNTHETIC.pdf)，并验证其中编辑文字、K011引用及待审核标记。
这是合成条件与测试文字，不是真实教师意见或已批准教案；未在真实Mac/Safari的系统打印对话框实测。

### 视频动作分析

- 真实视频仍使用既有本机MediaPipe、几何和V4/V5；上传、授权、限额、预览及关键点叠加不改。
- 页面提供上传区、运行状态、质量提示、可跳转时间的候选事件时间轴和中文复核选项。
- 缺模型、独立环境、FFmpeg等条件时明确列出，真实分析按钮保持不可用；不把文件存在当作已成功识别。
- 可点“试用合成演示”，它只复用原几何/V4/V5，未调用MediaPipe，没有真实原片；质量比例与关键点是构造值。
- 真实视频路径不把合成结果作为故障回退。二维变化不能判断真实用刃、重心、技术合格或官方评分。

### 教师反馈

1. 先有一份已保存L05和同浏览器中的ready分析任务。
2. 打开教师反馈，填写匿名代号、实际观察及下一次复练任务；先保存草稿。
3. 只有合成任务才允许显式填入标有“合成演示”的示例；真实视频不自动编造教师意见。
4. 自行核对并勾选后“本地自报确认”。身份未认证，不等于专项审核，知识状态不变。
5. 事件、教案或知识依据变化后，重新核对/打印会显示待教师确认；修改文字也回到草稿。
6. 可查看历史、恢复当前会话记录、删除或新建本次观察；新建前有未保存文字会提示。
7. 使用中文反馈打印稿留档。完整JSON仍保留在高级模式，不要求普通教师理解数据结构。

## 安装与保存边界

- 本轮不是签名Mac安装包：首次项目主Python环境仍须维护者准备。不能把云端Linux .venv复制到Mac，也没有声称本轮在用户Mac实测。
- 主环境就绪后教师只需双击启动；视频初次环境准备仍用已有setup_local_video.command，可能需要维护者提供FFmpeg与官方模型下载网络。主页和合成演示不依赖真实模型。
- SQLite知识与材料声明默认.local/coachloop-kb/knowledge.sqlite3，目录0700/数据库0600，重启保留；备份与删除沿用P3.4说明。
- 教案/反馈仍是原私有进程内存和双会话隔离；视频任务20分钟、视频会话30分钟、服务退出清空；及时打印或在高级模式导出。没有新增学生身份或云端账号。
- 离线PDF不会自动随知识撤回更新，使用前重新核对；不把真实学生视频、身份或私有反馈提交共享知识库或GitHub。
