## 来源和审核边界

L05的K011是课程资料提取原则，K018是课程自拟进阶，K019是课程自拟评价建议；不能冒充教材原文。
K010 v2（L04先修）定位王树本PDF91／印刷77图29左前压步；K012 v2定位李乡状PDF39／印刷29。
王树本PDF94／印刷80图33为后压步；李乡状PDF36／印刷26后交叉步滑行、PDF41／印刷31后压步不能混作本课依据。
P3.4原页核验只解决可见支持关系，不替代逐条专项意见，也不认证全部候选。

本轮不改知识、来源声明、审核决定或SQLite格式。所有数据沿用既有包；原始教材扫描不进入本验收包。
教师文稿、软件演示与合成反馈都不改变pending；正式专项教学仍需逐条审核和现场条件确认。

## 复现

```sh
PYTHONPATH=src .venv/bin/python -B scripts/prepare_course_mvp.py --output-dir work/course-mvp-new --docx
PYTHONPATH=src .venv/bin/python -B scripts/verify_l05_application_browser.py --course-mvp
```

输出目录必须全新。生成器只使用临时SQLite加载已有P3.2/P3.4包，执行现有API；临时库退出即删，不修改默认本地数据。
local-api-exports保存八个真实HTTP导出（含随机ID与生成时间，仅本地复现），不提交公开GitHub。
Word排版仅由可选--docx调用已安装python-docx；未新增应用运行依赖，已交付的Word可直接使用。
本轮真实库完整快照前后不变；私有教案仍是进程内存、会话隔离，退出清空，须手工导出。
