# 超星学习通课程建设资源清单与导入建议

状态：资源筹备建议；未登录、上传或发布学习通，未验证学校租户权限、模板或接口。
resource-catalog.json是本项目盘点清单，**不是学习通官方导入模板**；course-inventory.json是阅读投影，不是平台或教案API导入格式。

## 建议的八个章节

按L01–L08原顺序建章，名称照现有目录，每章标明45分钟及“待审核教学草稿”。
保留原24个候选备课主题的独立入口，不把主题当作8课次或额外章节自动导入。
每章建议组织为：课次说明→目标与先修→待审教案→知识定位与状态→资源检查→观察任务草稿→教师反馈。

## 人工导入与核对流程（建议，尚未执行）

1. 由课程负责人在有权限的学校租户确认建课、章节、附件格式、文件大小、任务/问卷及发布权限，取得实际可用的官方模板。
2. 先建不发布的教师检查空间（若租户支持），人工建立8章；上传经过审核与授权的文档，首轮只验证L05。
3. 对照资源清单核对文件名、文稿版本、knowledge_id/版本/source_id、出处及待审核标签；检查中文、表格与链接。
4. DOCX优先保留可编辑原件；如平台只适合PDF展示，由教师在Word/WPS本地导出并人工检查分页。转换文件仍标明pending，不上传空白审核表当作通过证明。
5. 本地CoachLoop导出的JSON是可追溯留档，不是学习通可执行课件。不要把localhost:8767当作学生可访问的网址，也不为导入改成公网服务。
6. 在平台实际支持且权限明确时，人工创建讨论与反馈入口。用明确标记的测试账号/数据检查，不产生真实学生测评结论。
7. 发布前核对教材授权、逐条专项意见、学情和现场安全；记录实际操作者与检查结果。当前缺证内容继续保留教师草稿，不发布为正式技术教学。

## 文件与版本建议

使用L05_教案_MVP-review-1_pending等清楚命名；知识版本与文稿版本分开记录。
resource-catalog.json保留ready_for_review、missing、local_restricted等准备状态；这些不是系统专业审核状态。
普通JSON导入不能改变专业审核状态，课件上传也不能提升知识可信等级。
离线材料和平台副本不会自动随知识撤回刷新。知识更新、失效或审核撤回后，负责人须撤下旧附件并重新核对引用，
再手工替换平台副本；本轮没有开发学习通同步、自动清理或发布功能。
