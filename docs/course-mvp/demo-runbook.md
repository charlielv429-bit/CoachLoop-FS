# 课程展示演示流程

目标：选择课次→查看知识依据→编辑教案→保存与导出→教师反馈。
演示者提前说明：软件操作验收使用合成学情，不是实际授课；知识与教师填写均待复核，不作技术评分。

## 启动与材料

```sh
PYTHONPATH=src .venv/bin/python -B scripts/run_prelesson_console.py --port 8767
```

仅本机打开http://127.0.0.1:8767。沿用现有本地访问、会话、Origin/CSRF与身份边界。
若知识库已存在，不重导入或重置。检查本地“8课次课程目录与知识库”显示实际数据；本次验收库为23 IDs/27版本/50声明/0审核决定。
其他机器初始可能空库：允许展示空库组织框架，不能把本报告的数字当作那台机器的状态。
需要带真实候选的可复现演示时，以下命令只在新建的临时目录重建现有包并做API验收，不更改真实SQLite：

```sh
PYTHONPATH=src .venv/bin/python -B scripts/prepare_course_mvp.py --output-dir work/course-mvp-fresh
```

输出目录必须不存在；含八课Markdown、阅读清单和local-api-exports内八个实际HTTP导出。
这不是启动器，也不把该临时库安装为默认库。可选--docx使用已安装python-docx生成L05送审Word；没有该库时使用已交付Word或Markdown，不新增运行时依赖。

## 建议10分钟展示脚本（演示时长不是课程时长）

| 环节 | 演示操作 | 应看到的结果 | 不能声称的结果 |
|---|---|---|---|
| 1分钟：选课 | 在目录查看L01–L08，打开“按课次备课模式”选L05 | 原8课顺序、45分钟、待审核；24主题入口仍独立 | 8课已通过专项教学审核 |
| 2分钟：查看依据 | 展开L05三组素材、资料登记和独立材料声明；查看K010先修定位核查 | 专项素材K011/K012、进阶K018、评价K019；ID/版本/source_id/页码/pending；受控引用为空 | 原页定位核对等于专项通过 |
| 2分钟：生成与编辑 | 填合成学情/场地/装备，不勾选先修；生成后修改目标、组织、资源与七类L05内容 | 9/29/7；冰上暂缓；教师填写待复核 | 教师自报可以上冰就绕过限制 |
| 1分钟：保存与历史 | 点击保存教师修改、查看历史 | 版本1→2；修改记录local_unverified_operator／pending_review | 系统认证了教师身份 |
| 1分钟：导出 | 先保存再导出，打开JSON核对课次、版本、状态和记录 | 实际下载L05-pending-review-framework.json；技术指导为空 | JSON可直接导入学习通或重新导入私有教案 |
| 2分钟：教师反馈 | 展示L05送审Word的逐条意见与验收反馈栏；在L05评价观察项填“合成反馈草稿，非实际评价”，保存成版本3并导出 | 反馈草稿随教案追加版本，仍待复核；真实意见表为空 | 已获得真实教师认可或学生测评 |
| 1分钟：资源交接 | 打开学习通资源清单与导入建议；切换旧主题/视频/反馈页展示入口 | 原有功能入口保留；平台建设仍是待办 | 学习通已上线或未上传视频已有训练反馈 |

不需要上传学生视频完成本次演示。现有“训练反馈”页只引用本机视频记录；没有获授权真实视频时仅说明其输入依赖，
不把L05评价文本伪装为视频训练结果。非L05课次的完整教师反馈使用通用空白表，当前没有独立反馈API。

## 保存、隐私与失效

- 知识及材料声明：默认.local/coachloop-kb/knowledge.sqlite3，重启保留；复用P3.4完整备份步骤，不新增存储。
- 教案/反馈草稿：现有进程内存，浏览器签名会话隔离，全服务100快照/2MiB；刷新保留，退出、重启或丢失会话后无法恢复旧私有稿。导出副本由教师自行保管。
- Word/Markdown：离线编辑与留档，不会自动回写或升级系统审核。真实返回意见保存本地私有目录，不未经确认提交GitHub。
- 旧教案关联知识更新或撤回时，服务端导出检查并撤下失效引用，要求重新生成；离线Word和学习通副本须人工重新核对。
- 展示包中的班级和反馈文字均为合成验收场景；不得在结束时说“已完成真实授课/测评”。

## 演示失败时

空库：仍生成组织框架，展示资料缺项；不手工伪造已审核知识。
先修或资源不足：展示暂缓提示，这是预期保护。未保存不能导出：先保存。
版本冲突：重新查看当前稿，不覆盖并发修改。教案进程已退出：重新生成，不假称历史已持久化。
